# Portfolio

The Astro site that lives next to Signal Portrait, in this same repo. Alba (MIT, Andrei Alba / Xoco Themes) is the base. It is reskinned to the Fingerprint palette and served at `/portfolio`.

`npm run dev` from the repo root starts both apps. The demo's **More about me** button opens `/portfolio/`. This site's **Signal Portrait** link goes back to `/`.

The theme's `LICENSE` stays in this folder. Fonts are SIL Open Font License. Icons are ISC/MIT.

Case studies are the short versions of Electrolux, ArcelorMittal, Robovision, Unilin, and Tabulas. Years, the CV PDF, and the longer write-ups are not in yet.
